# AutoSwitcher V2 — Architecture

**Status:** in development on branch `v2`
**Supersedes:** v0.4.1 core (`core.py` monolith)

## Why a rewrite

The v0.4.x review (2026-06) found the detection pipeline built on a false
foundation and measured real damage with the project's own dictionaries:

1. **`key.char` is NOT "always EN".** pynput caches the keyboard layout of its
   listener thread at startup — i.e. the user's *default Windows input
   language*. For users whose default is Ukrainian (the target audience,
   especially with start-at-boot), every `key.char` is Cyrillic and the whole
   dual-translation scheme inverts.
2. **UK→EN corrected on `en_valid` alone** (no `uk_valid` check) against a
   junk-filled 370k wordlist → 1.74% (frequency-weighted) of correctly typed
   Ukrainian destroyed («буде»→",elt", «руки»→"herb").
3. **No caret awareness** — buffer survived mouse clicks and focus changes;
   corrections deleted unrelated text; Alt+Tab fired corrections.
4. **150 ms wall-clock cooldown** to ignore self-injected events also ate real
   keystrokes and the Alt of an immediate undo.
5. Whitelist stored on-screen (Cyrillic) text but compared the EN buffer —
   whitelisting never worked for the main correction direction.

## V2 principles

### 1. Capture physical keys, not translated chars
The listener records **virtual-key codes + shift/caps state**. `keymap.py`
derives the EN-layout character itself (US-QWERTY VK table), and the UK
rendering via the existing translation tables. The active layout of the
*foreground window* is queried per word. pynput's char translation is no
longer trusted for anything.

### 2. One symmetric decision rule (engine.py — pure, no I/O)
For the word's two renderings (`shown` per the foreground layout, `other`):

```
correct  ⇔  other_valid AND (NOT shown_valid
                             OR  logP(other) − logP(shown) ≥ DOMINANCE)
```

- Validity: frequency dictionary (`freq_en.txt`, count-thresholded — junk-free,
  unlike words_alpha) + curated short-word list for EN; pymorphy2 + custom list
  for UK.
- Probabilities from the two frequency dictionaries with floors for
  morphology-valid-but-unlisted words.
- Punctuation is handled by generating *both* candidate readings (full token —
  punct keys may be letters in the other layout, e.g. `,fub`→«баги»,
  `,elt`→«буде» — and edge-stripped token with punct re-attached) and scoring
  them. No special-case heuristics.
- Same rule both directions; the v1 asymmetry (and its 1.74% destruction rate)
  is gone. The dictionary benchmark in `tests/test_benchmark.py` enforces
  false-positive/false-negative ceilings so regressions fail CI.

### 3. Listener enqueues; worker decides
The pynput callback only filters injected events (pynput ≥1.8 passes
`injected` on Windows — no more time-window cooldown), snapshots
(vk, modifiers, caps, foreground hwnd) and enqueues. A single worker thread
owns ALL mutable state: buffer, undo record, whitelist, config. No locks
around detection state, no re-entrancy guards, no dropped keystrokes.

### 4. The buffer knows where the caret is
- Every key event carries the foreground hwnd; the word remembers the hwnd and
  layout it started in. If either changed by the boundary — discard, never
  correct.
- A mouse listener resets the buffer on any click.
- Boundary keys with non-shift modifiers held (Alt+Tab, Ctrl+Space…) flush
  without correcting.
- Ctrl/Alt+letter events never enter the buffer (no `'\x13'` pollution).

### 5. Atomic, app-owned injection
`injector.py` sends the whole correction (backspaces + replacement +
separator) as **one batched `SendInput` array**, every event tagged with a
magic `dwExtraInfo`, so our own events are identified positively (defense in
depth on top of pynput's `injected` flag).
- Space is the only correcting boundary by default. Enter/Tab flush only
  (chat apps have already submitted; forms have already moved focus) —
  configurable.
- Undo only applies when nothing was typed since the correction.

### 6. State that survives
- Config in `%APPDATA%/AutoSwitcher/` (migrates the old exe-dir config),
  written atomically (temp file + `os.replace`) behind a lock.
- Correction counter persisted debounced, not per-keystroke.
- Whitelist stores the **canonical physical-key form** (EN chars), so it
  matches regardless of which direction a correction fired; old Cyrillic
  entries are migrated on load.

### 7. Clean data
- `dictionaries/freq_uk_clean.txt` — generated by `tools/clean_freq_uk.py`:
  the OpenSubtitles list filtered through pymorphy2 (drops «что», «как» and
  the rest of the ~25% Russian contamination). T9-UK and the UK frequency
  model load only the clean file.
- `dictionaries/en.txt` (previously dead) now loads as custom EN additions.

## Module map

| module | role | replaces |
|---|---|---|
| `keymap.py` | VK→EN char; EN↔UK rendering; variants | `mapper.py` |
| `dictionaries.py` | validity + log-probabilities, custom dicts | `validator.py` |
| `engine.py` | pure word decision (testable, no I/O) | `_check_word` ladder |
| `injector.py` | batched tagged SendInput | `_type_unicode` + sleeps |
| `winapi.py` | foreground hwnd/layout/app, caps state | inline ctypes in core |
| `appconfig.py` | atomic config in %APPDATA%, migration | `load/save_config` |
| `pipeline.py` | listener → queue → worker; buffer, undo, whitelist, hotkey | `core.py` event logic |
| `core.py` | thin facade re-exporting `LayoutSwitcherCore`, `VERSION` | old monolith |
| `corrector.py` | T9 (shared impl, punct-safe, clean dict) | old corrector |

`settings.py`/`tray.py`/`main.py` keep their structure; settings toggles now
write only the field that changed (no more clobbering tray-made changes).

## Testing

- `test_keymap.py` — VK tables, round-trips, variants.
- `test_engine.py` — decision rules incl. every confirmed v1 bug as a
  regression case.
- `test_pipeline.py` — typing flows with fake winapi/injector: focus changes,
  mouse resets, modifier-held boundaries, injected filtering, undo/whitelist.
- `test_benchmark.py` — frequency-weighted FP/FN ceilings over the real
  dictionaries (the measurements that condemned v1, now enforced).
